# Farken's World Unity prototype

This folder contains the first Unity port of the browser prototype.

Open `Assets/Scenes/SampleScene.unity` and press Play. The runtime bootstrap creates a small survival test world without requiring scene setup or imported assets.

Controls:

- `WASD` - move
- `Left Shift` - sprint
- `Space` - jump
- `Mouse` - look
- `E` - harvest the targeted tree or rock
- `Escape` - release the mouse cursor
- `Left Click` - capture the mouse cursor again
