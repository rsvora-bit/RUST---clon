# Farken's World - Unity Prototype 0.1

Open `Assets/_FarkensWorld/Scenes/Main.unity` and press Play.

## Controls

- `WASD`: move
- Mouse: look
- `Space`: jump
- `Left Shift`: sprint and drain stamina
- `LMB`: harvest resources, break road loot, or place a build preview
- `E`: pick up drops, drink, or open a container
- `Tab`: inventory, crafting queue, and active container
- `B`: building menu
- `1-6`: hotbar
- `R`: rotate build preview
- `U`: upgrade targeted build
- `T`: repair targeted build
- `X`: demolish targeted build
- `Esc`: close a panel or pause
- Backquote or `F10`: developer console

Useful console commands include `help`, `give wood 500`, `give stone 500`, `giveall`, `god toggle`, `save`, `load`, and `report`.

The prototype intentionally uses generated primitives and runtime materials. They can be replaced with original models and textures later without replacing the gameplay systems.
